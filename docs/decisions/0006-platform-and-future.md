# 0006 — Platform, future users, learning and budget

- **Status:** accepted
- **Date:** 2026-10-11
- **Source:** `docs/plans/01-discovery-followups.md` Q17, Q18, Q20, Q21; clarification 6

## Decision

- **Platform:** a web page used mainly on this Mac.
- **Public graph:** briefly showing the real graph on a public website is accepted. The owner chose to build quick and fail fast. When this is built, it should be easy to switch off.
- **Future users:** keep the design open to other people signing up later. For example, the data model should be able to hold data for more than one user. Accounts and sign-in are not built now.
- **Learning:** this is a learning project. Choose tools that teach servers and databases step by step, and explain each new idea when it's introduced.
- **Budget:** about 100 TWD per month for personal use. That covers AI reading, categorization and summaries. Expanding to other users means another conversation about cost.

## Consequences

- Choosing tools for learning means slower progress to the first chart, in exchange for understanding the setup.
- A public page shows real financial data to anyone who has the link while it's up.
- The technical plan should estimate the monthly AI cost against the 100 TWD budget.
